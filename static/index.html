Method

SNR is active-speech RMS divided by noise RMS, set before an 8 kHz μ-law roundtrip. Noise is synthesized per scene and seeded once, so both arms hear the identical line. The conditioned arm applies a 260–3500 Hz bandlimit and a spectral gate; the raw arm is untouched. Slot exact means member, litres, fat and shift all match the authored script. “Would auto-log wrong” is a parse that passes every deterministic gate but is still wrong — the reason the readback exists.

The shipped line does not choose one arm. It decodes both, pre-fills only when the two parses agree on all four values (or exactly one validates), and sends every other turn to readback or re-ask. The two-path table is scored from the same runs; it adds no third decode, and every entry still needs an operator confirmation.

The live provider check is a separate run of the same 24 × 4 × 2 matrix through Gnani Prisma v3.0. It is not merged into the frozen benchmark or its claim. Prisma returns Tanglish, so WER against the Tamil scripts is not comparable; slot exactness and the gate are the metrics reported.

Integrity strip

  • Synthetic voices and names. No real farmers, phone numbers, Aadhaar, PAN or account numbers.
  • Provider mode comes from the running server. The frozen benchmark is a local faster-whisper run; a live Gnani provider check is reported separately in Evidence.
  • Our clips, our benchmark. Every number is from 24 authored clips; no field data, no bought engagement.
